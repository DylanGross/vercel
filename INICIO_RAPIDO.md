# 🚀 INICIO RÁPIDO - Chatbot Next.js

## ⚡ 3 Pasos para Empezar

### 1️⃣ Obtén tu API Key (2 minutos)
1. Ve a → https://openrouter.ai/
2. Regístrate gratis
3. Ve a → https://openrouter.ai/keys
4. Crea una nueva key
5. Cópiala

### 2️⃣ Configura el Proyecto (30 segundos)
```bash
# Abre .env.local y pega tu API key
OPENROUTER_API_KEY=sk-or-v1-TU-KEY-AQUI
```

### 3️⃣ Inicia y Prueba (30 segundos)
```bash
npm run dev
```
Abre → http://localhost:3000

## 🆘 Problemas Comunes

**"API key no configurada"**
→ Edita `.env.local` con tu key real

**"El bot no responde"**
→ Verifica que `npm run dev` esté corriendo

**"Error 401"**
→ Tu API key es inválida, crea una nueva
